# 🔢 Задачи: Ввод-вывод и операции с числами

В этом модуле собраны задачи на работу со стандартным вводом/выводом (`Scanner`, `System.out.print`), арифметические операции, а также деление нацело (`/`) и взятие остатка (`%`).

---

## 🟢 Уровень: Легкий (Базовый ввод-вывод)

### Задача 1: Приветствие пользователя
**Условие:** Программа должна запросить у пользователя его имя через консоль, а затем вывести приветствие.
* **Входные данные:** `Иван`
* **Выходные данные:** `Привет, Иван! Добро пожаловать в мир Java.`

<details>
<summary>💡 Подсказка по реализации</summary>

Используйте класс `Scanner` для чтения строки:
```java
Scanner scanner = new Scanner(System.in);
String name = scanner.nextLine();
```
</details>

---

### Задача 2: Сумма трех чисел
**Условие:** Пользователь вводит три целых числа. Программа должна вывести их сумму.
* **Входные данные:** `5`, `10`, `15`
* **Выходные данные:** `Сумма чисел равна: 30`

---

## 🟡 Уровень: Средний (Арифметика и остаток от деления)

### Задача 3: Разворот трехзначного числа
**Условие:** Пользователь вводит положительное трехзначное число (например, `357`). Программа должна «развернуть» его и вывести задом наперед (`753`). *Использовать циклы или перевод в строку запрещено — только математические операции.*
* **Входные данные:** `482`
* **Выходные данные:** `Результирующее число: 284`

<details>
<summary>💡 Подсказка по реализации</summary>

Чтобы достать отдельные цифры, используйте `/ 10` и `% 10`:
* Последняя цифра: `482 % 10 = 2`
* Средняя цифра: `(482 / 10) % 10 = 8`
* Первая цифра: `482 / 100 = 4`

Затем соберите число обратно: `(2 * 100) + (8 * 10) + 4`.
</details>

---

### Задача 4: Электронные часы
**Условие:** С начала суток прошло `N` минут (пользователь вводит `N`). Программа должна вывести, сколько часов и минут покажут электронные часы. 
* **Входные данные:** `150`
* **Выходные данные:** `02:30` (или `2:30`)

## 🔴 Уровень: Сложный (Округление и типы данных)

### Задача 5: Обмен значений без третьей переменной
**Условие:** Даны две целочисленные переменные `a` и `b`. Пользователь вводит их значения. Программа должна поменять их значения местами **без создания третьей (временной) переменной** и вывести результат.
* **Входные данные:** `a = 5`, `b = 10`
* **Выходные данные:** `После обмена: a = 10, b = 5`

<details>
<summary>💡 Подсказка по реализации</summary>

Используйте простую математику сложения и вычитания:
```java
a = a + b; // теперь в 'a' лежит сумма обоих чисел
b = a - b; // из суммы вычитаем старое 'b', получаем старое 'a' и записываем в 'b'
a = a - b; // из суммы вычитаем новое 'b' (которое теперь старое 'a'), получаем старое 'b'
```
</details>
